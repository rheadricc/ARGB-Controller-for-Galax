ARGB CONTROLLER FOR GALAX 1.0.0 - THIRD-PARTY NOTICES
==================================================

ArgbGalax.exe is a framework-dependent .NET 10 single-file application. It runs on the
Microsoft .NET 10 Desktop Runtime installed on your PC, which is not included in this
download. The executable contains the .NET application host (apphost), licensed under the
MIT License (text below).

The program calls, without redistributing them, components that are already on your PC:
  - NVIDIA driver libraries nvapi64.dll and nvml.dll (lighting I2C bus, fan status, telemetry)
  - Windows HID, SetupAPI and firmware-table APIs
  - SteelSeries GG's local GameSense server, when SteelSeries GG is installed and running

Hardware protocol reference, no source code included: the GALAX V2 RGB register map,
the ASUS Aura keyboard direct-mode packets and LED order, and the MSI Mystic Light 185-byte
feature report layout were learned from the OpenRGB project
(https://gitlab.com/CalcProgrammer1/OpenRGB, GNU GPL v2) and its issue #4826. ARGB Controller
for Galax is its own implementation and does not contain OpenRGB source files.
